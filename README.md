# Hospital Management System (HMS)
SWE3020B Software Quality Assurance and Security project. 

# Context
Small clinic often track patients and appointments on paper or spreadsheets,
which causes double bookings, lost records and privacy risks

# Core functionalities
1. Patient Registration: create, view and search patients
2. Appointment Scheduling: book, cancel and view appointments, with double booking prevention
3. Medical Records: doctors add and view diagnoses and notes
4. Role based Login/access

# Target Users
1. Receiptionist
2. Doctor
3. Administrator

**Stack:** Python 3.12, Flask, SQLite, pytest, Docker, GitHub Actions.
